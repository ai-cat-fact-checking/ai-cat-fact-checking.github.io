事實貓咪偵探社｜隱私權政策（Privacy Policy）

更新日期：2026-11-11｜適用於「真假 Meow 一下」1.0.0 版起

重點摘要

  • 文章分析在你的瀏覽器裡進行。偵探社伺服器不會收到你閱讀的文章內容，也不保存你的 Gemini API Key。
  • 只有在你按下貓咪、使用右鍵選單或快速鍵時，擴充功能才會讀取目前的頁面；它不會在背景分析你瀏覽的網站。
  • 選擇「雲端 AI」或按下「查證」時，內容會用你自己的 API Key 直接從瀏覽器送到 Google，不經過偵探社。
  • 偵探社伺服器只用於選用的「讀者討論」：展開討論區時會收到文章網址；登入並留言時會保存你的留言與 Google 帳號的基本資料。
  • 我們不出售資料、不投放廣告，擴充功能本身也不使用任何流量分析工具。

本政策由「事實貓咪偵探社」（以下稱「我們」）訂定，說明「真假 Meow 一下」Chrome 擴充功能、偵探社伺服器（api.factcat.xyz）與官方網站（factcat.xyz）如何處理你的資料。

一、擴充功能什麼時候讀取網頁

  • 只有在你按下工具列的貓咪、使用右鍵選單「用真假 Meow 一下分析這頁」或「分析選取的文字」，或按下快速鍵（Alt+Shift+M）時，才會讀取目前分頁的內容。
  • 如果你在側邊欄按下「允許讀取並分析」，Chrome 會詢問是否讓擴充功能存取該網站。允許之後，在同一個網站開啟側邊欄時就不必再按一次貓咪。這項權限可以隨時在 Chrome 的擴充功能設定中收回。
  • Chrome 內部頁面、擴充功能商店等受限制的頁面無法分析。
  • 頁面上的標示是用瀏覽器內建的標示功能畫出來的，該網頁本身的程式也看得到哪些文字被標示。擴充功能不會改動網頁文字，也不會把分析結果寫進網頁。

二、不同功能的資料流向

功能送出的資料送到哪裡
基本檢查不送出任何資料只在你的電腦上處理
本機 AI不送出任何資料（第一次使用時，Chrome 會從 Google 下載內建模型）只在你的電腦上處理
雲端 AI文章的標題、內文、作者、發布時間與網站名稱用你自己的 API Key 直接送到 Google Gemini API
查證你選擇查證的說法、相關上下文，以及文章標題、網站名稱與發布時間用你自己的 API Key 送到 Google，並使用 Google 搜尋比對資料
查詢這個網站的背景網站的網域名稱用你自己的 API Key 送到 Google
讀者討論（選用）文章網址；登入並留言時，還有留言內容、標籤與 Google 登入憑證偵探社伺服器 api.factcat.xyz；登入由 Google 處理

使用 Gemini API 時，內容的處理方式依 Gemini API 服務條款 與 Google 隱私權政策 辦理。使用免費方案時，Google 可能會用這些內容改進產品；不想這樣的話，請使用付費方案，或改用基本檢查、本機 AI。

三、存在你電腦上的資料

  • Gemini API Key 與偏好設定：只存在這台電腦的 Chrome 裡（擴充功能的本機儲存空間），不會同步到其他裝置，也不會送到偵探社伺服器。
  • 分析結果：只暫存在瀏覽器的工作階段記憶體中，關閉瀏覽器後就會清除。
  • 網站背景查詢結果：只包含網域名稱與公開資料，在這台電腦保存 30 天，避免重複查詢。
  • 讀者討論的登入狀態：Google 發給擴充功能的登入憑證（約一小時後失效），以及你的 Google 帳號編號、名稱、Email 與大頭貼網址，用來顯示登入狀態與送出留言。

你可以在擴充功能的「設定 → 隱私與資料」按「清除這台電腦上的所有設定與快取」一次刪除以上資料；移除擴充功能時，Chrome 也會一併刪除。

四、偵探社伺服器保存的資料

偵探社伺服器只提供「讀者討論」。

  • 讀取留言：展開討論區時，伺服器會收到文章網址，用來找出這篇文章的留言。不需要登入，也不會為此建立任何紀錄。
  • 登入與留言：你用 Google 帳號登入後留言，我們會保存 Google 帳號編號、Email、顯示名稱，以及你的留言內容、標籤、文章網址與時間。
  • 公開顯示：其他讀者看得到你的顯示名稱、留言內容、標籤與時間；Email 不會公開。
  • 伺服器紀錄：為了維護服務，伺服器會記錄請求的時間、功能類別與結果代碼，不記錄文章網址與 IP 位址。為了防止濫用，伺服器會在記憶體中短暫使用 IP 位址計算請求次數（每 15 分鐘重新計算），不會寫入紀錄。
  • 保存期間：留言與帳號資料保存到你刪除或要求刪除為止；伺服器紀錄只保留維運所需的最近一小段時間，之後自動覆寫。

舊版（0.x）會在伺服器上保存加密後的 Gemini API Key，並快取文章的分析結果與網站資訊。1.0 版起不再這樣做；Chrome 把擴充功能更新到 1.0 版後，舊版留下的這些資料會從伺服器刪除。

五、擴充功能使用的權限

  • 目前分頁（activeTab）：在你按下貓咪、使用右鍵選單或快速鍵之後，暫時讀取並標示目前的分頁。
  • 選用的網站存取權：只有在你按下「允許讀取並分析」時才會詢問，用來讓同一個網站下次不必再按一次貓咪。
  • 執行指令碼（scripting）、側邊欄（sidePanel）、右鍵選單（contextMenus）、儲存空間（storage）：用來在頁面上擷取文章與標示、顯示側邊欄、提供右鍵選單，以及保存你的設定。
  • 身分識別（identity）、Google 帳號資訊（googleapis.com）與偵探社服務（api.factcat.xyz）：只用於選用的「讀者討論」登入與讀取、送出留言。

六、官方網站 factcat.xyz

  • 官網由 GitHub Pages 代管，並經由 Cloudflare 提供服務；這些服務商會依其政策處理連線所需的 IP 位址等技術資料。
  • 官網使用 Google Analytics 統計瀏覽人次與使用情況，會使用 Cookie。你可以在瀏覽器中拒絕 Cookie，或安裝 Google Analytics 停用外掛程式。
  • 官網的短網址（例如意見回饋）會轉到 Google 表單等外部服務，填寫後的資料依該服務的政策處理。
  • 擴充功能本身不使用 Google Analytics 或任何流量分析工具。

七、我們不會做的事

  • 不出售、出租你的資料，也不用於廣告。
  • 不蒐集你的瀏覽紀錄，也不在背景分析你瀏覽的網站。
  • 除了本政策所列情形，或依法令要求外，不會將你的資料提供給第三方。
  • 本擴充功能對使用者資料的使用與傳輸，遵守 Chrome 線上應用程式商店使用者資料政策，包括有限使用（Limited Use）規定。
    The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

八、資料安全

  • 擴充功能與伺服器之間、擴充功能與 Google 之間的連線都使用 HTTPS 加密。
  • 伺服器只接受由本擴充功能取得的 Google 登入憑證，並限制每個 IP 位址的請求次數。
  • 我們會持續檢查並修正安全問題；如果你發現漏洞，歡迎來信告訴我們。

九、你的權利

依個人資料保護法，你可以向我們查詢、閱覽、更正、刪除你的留言或帳號資料，或要求停止處理。請來信並附上你登入時使用的 Google 帳號 Email，我們會在確認身分後盡快處理。
